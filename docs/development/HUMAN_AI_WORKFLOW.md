# Human-AI Development Workflow

> **Status:** ACTIVE DEVELOPMENT PROCESS

DIABLO X3-NX is developed through a human-AI engineering workflow.

**GVM** defines the project direction, physical goals and acceptable robot behavior and performs real-world robot testing.

**ChatGPT** is used for system reasoning, planning, architecture review, documentation and preparation of tightly scoped engineering tasks.

**Codex** is used for controlled code inspection, diagnostics and implementation work on the development systems.

## Typical workflow

1. GVM describes the desired behavior or observed problem.
2. ChatGPT reduces the problem to one testable blocker or engineering step.
3. A constrained Codex task is prepared with explicit safety boundaries.
4. Codex inspects or changes only the allowed scope.
5. The result is checked through build, service or runtime evidence.
6. GVM performs the real-robot test when physical behavior is involved.
7. Only verified conclusions are carried into the next step.
8. Public material is prepared separately and requires GVM approval before publication.

## Why document this?

The Human-AI workflow is part of the technical history of DIABLO. It shows how planning, diagnostics, implementation and real-world validation are connected rather than presenting AI as a replacement for physical engineering work.

## Final validation

AI tools assist the engineering process; they do not represent sponsorship or ownership of the project. The real robot and measured runtime evidence remain the final validation source.
