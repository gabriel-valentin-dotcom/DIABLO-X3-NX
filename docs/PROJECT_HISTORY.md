# Project History

> **Status:** LIVING DOCUMENT / ACTIVE DEVELOPMENT

DIABLO X3-NX did not begin as a finished ROS 2 system. It began with the arrival of the original Direct Drive Technology DIABLO robot platform.

The first documented steps were simple and physical: the shipping package arrived, the transport case was opened, the original robot was inspected, and the identification plate documented the starting hardware.

![How the DIABLO project started](../media/images/project-history/how_the_diablo_project_started.jpg)

## The starting point

1. **Delivery** — the original DIABLO arrived in its shipping package.
2. **Transport case** — the robot was supplied in its dedicated Direct Drive Technology transport case.
3. **Original DIABLO robot** — this was the hardware base before the X3-NX development architecture was built around it.
4. **Identification plate** — the original platform identity was documented as part of the project record.

From this physical starting point, the project progressively evolved toward the current DIABLO X3-NX architecture with D-Robotics RDK X3, NVIDIA Jetson Xavier NX, ROS 2, LiDAR, depth vision, interaction, safety logic and real-robot validation.

This page will be extended over time with additional milestones, photographs and development stages so that the repository preserves not only the current system, but also how the project evolved.
