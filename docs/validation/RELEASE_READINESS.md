# Release Readiness

> ⏳ **NOT RELEASE READY — ACTIVE DEVELOPMENT**

DIABLO X3-NX will not be described as finished or deployment-ready until the complete system has repeatable real-world evidence behind that claim.

## Future release-ready criteria

A future release-ready milestone should include evidence for:

- stable boot and runtime startup
- reliable controller communication
- repeatable telemetry delivery
- verified motion commands
- verified safety holds and obstacle behavior
- repeatable FOLLOW behavior
- defined target-loss behavior
- camera and LiDAR runtime stability
- safe INTERACT behavior
- controlled AUTO behavior within its documented scope
- power-system stability under realistic robot load
- recovery from relevant runtime faults
- repeated longer-duration tests
- documented known limitations

## External feedback

Feedback from other developers and real users is valuable before a final readiness claim. Public development is intended to make architecture, limitations and test evidence visible early enough for useful technical discussion.

## Final milestone

A future stable release may be marked with a versioned Git tag and a dedicated validation report.

Until that milestone exists, the public `main` branch represents active development and should not be interpreted as a finished product.
