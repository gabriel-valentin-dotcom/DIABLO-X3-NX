# CAM

> **Status:** VERIFIED / ACTIVE DEVELOPMENT

CAM controls the RealSense D435 runtime and associated preview/perception path.

## Current behavior

- Camera runtime can be activated on demand.
- Higher-level perception consumes camera data when required.
- Camera runtime is kept separate from always-on robot control.
- This allows the project to avoid running unnecessary sensor workloads continuously.
