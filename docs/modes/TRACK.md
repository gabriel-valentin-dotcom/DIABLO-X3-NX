# TRACK

> **Status:** IN DEVELOPMENT

TRACK represents the target-tracking layer used to maintain target direction/state for higher-level behavior.

## Current direction

- Tracking state is separated from FOLLOW motion.
- Target state can represent left, center, right or missing conditions.
- Tracking information is used as an input to higher-level robot logic.
- Tracking does not itself imply that the robot is allowed to move.
