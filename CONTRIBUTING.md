# Contributing to DIABLO X3-NX

> 🚧 **ACTIVE DEVELOPMENT**
>
> DIABLO X3-NX is a real-hardware robotics project under continuous development. Interfaces, packages, parameters and behavior may change.

## How to contribute right now

The most useful contributions at this stage are:

- technical questions
- architecture feedback
- ROS 2 suggestions
- safety observations
- ideas for testing and validation
- hardware integration experience
- reproducible bug reports

GitHub Discussions is the preferred place for general questions, design ideas and technical discussion. Issues can be used for concrete, reproducible problems once enough information is available.

## Status language

Project documentation uses the following labels:

- **VERIFIED** — demonstrated on the physical robot
- **IN DEVELOPMENT** — active and changing
- **EXPERIMENTAL** — exploratory and may be replaced
- **PLANNED** — intended future work
- **DEPRECATED** — retained only for development history

A component marked VERIFIED may still continue to evolve.

## Source-code contributions

Public source snapshots will represent real DIABLO development code, not reconstructed examples. Before code is accepted or published it should be reviewed for:

- technical relevance
- safety implications
- credentials or private data
- machine-specific information
- third-party licensing
- obsolete or diagnostic-only content

## Real-robot evidence

For behavior that affects physical motion, software output alone is not considered sufficient proof. Real-robot testing remains the final validation step.

## Project direction

The goal is not to present unfinished work as a finished product. The goal is to make the real engineering direction visible and useful to other developers while DIABLO evolves.
