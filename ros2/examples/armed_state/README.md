# ARMED State Example

> 🚧 **WORK IN PROGRESS — ACTIVE DEVELOPMENT**
>
> This directory is reserved for a selected real ROS 2 code snapshot from the current DIABLO X3-NX development workspace.

> The implementation is still evolving and may change as the real robot is developed and tested.

## Purpose

The ARMED state is part of the DIABLO X3-NX movement-permission and safety-state architecture.

This public example is intended to show the project direction and how runtime state is connected to higher-level robot behavior.

It is **not** a complete DIABLO control stack and should not be treated as a stable public API.

## Source-code status

The real source snapshot is **not published yet**.

Before any source file is added here, the current productive code from `diablo_ws` will be reviewed for:

- technical relevance
- active development status
- credentials or private information
- machine-specific data
- third-party licensing
- obsolete experiments
- consistency with the real robot state

No synthetic or reconstructed ARMED implementation is published here.

When the source snapshot is added, it will represent reviewed real development code and may continue to evolve afterward.

## Development principle

DIABLO X3-NX intentionally shows selected work while it is still under active development.

The goal is to make the technical direction understandable to other ROS 2 developers without presenting unfinished work as a finished product.
