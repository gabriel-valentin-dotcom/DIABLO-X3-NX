# License Status

> 🚧 **OPEN-SOURCE LICENSE PREPARATION IN PROGRESS**

DIABLO X3-NX is intended to become an open-source project, but a single project-wide license has **not yet been finalized** for the current development snapshot.

The code is publicly visible so developers can follow the architecture and development direction. Public visibility alone should not be interpreted as granting permissions beyond applicable law or any explicit license notice contained in an individual file/package.

Some current ROS 2 package metadata still contains development-stage or provisional license declarations. These will be normalized before a formal stable open-source release.

Third-party software is not relicensed by this project and remains governed by its respective upstream license.

A formal project-wide licensing decision will be documented before the first stable open-source release.
