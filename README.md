# DIABLO X3-NX

**Independent ROS 2 robotics development project by GVM**

> 🚧 **EARLY PUBLIC PREVIEW — WORK IN PROGRESS**  
> DIABLO X3-NX is under active development. This repository is intentionally being opened early so interested people can follow the project as it evolves. Documentation, photos, diagrams and real-robot videos will be added step by step.

DIABLO X3-NX is a real-hardware robotics project based on the Direct Drive Technology DIABLO platform, extended with a D-Robotics RDK X3 and an NVIDIA Jetson Xavier NX.

The project focuses on practical robot control, perception, safety, person following and on-demand interaction using ROS 2.

**Current principle:** only functions and capabilities that have been verified on the real robot are presented as working features.
