# DIABLO X3-NX

**Independent ROS 2 robotics development project by GVM**

DIABLO X3-NX is a real-hardware robotics project based on the Direct Drive Technology DIABLO platform, extended with a D-Robotics RDK X3 and an NVIDIA Jetson Xavier NX.

The project focuses on practical robot control, perception, safety, person following and on-demand interaction using ROS 2.

> **Status:** Active development. This repository is currently being prepared before its public launch.
