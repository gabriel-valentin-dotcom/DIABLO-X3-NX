# DIABLO X3-NX — Roadmap

> 🚧 **WORK IN PROGRESS**

The roadmap is directional and may change as real-robot testing reveals better approaches. It is not a promise of fixed delivery dates.

## Phase A — Public technical foundation

- Repository structure
- Project overview
- Architecture and hardware documentation
- Safety overview
- Operating-mode pages
- ROS 2 interfaces and data flow
- Current-status and development-workflow documentation

## Phase B — Media evidence

- Current UI images
- Robot photographs
- Hardware and sensor images
- Architecture diagrams
- Short real-robot demonstration videos
- Longer project-overview video

Media will be added when time allows; documentation can continue growing independently.

## Phase C — Selected software publication

Reviewed ROS 2 packages, examples or interfaces may be published after:

- security review
- licensing review
- third-party attribution review
- removal of private machine-specific details
- technical verification

## Phase D — Deeper technical documentation

- Mode internals
- Data flow and ownership
- Tuning philosophy
- Test methodology
- Diagnostics and failure analysis
- Design evolution and replaced approaches

## Phase E — Community feedback

GitHub Discussions will be used for questions, suggestions and engineering feedback. Useful ideas may be evaluated and documented if they become part of the project.
